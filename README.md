# Car Photography

Django уеб приложение за галерия с автомобилни снимки. Посетителите могат да разглеждат снимки, да търсят по марка или модел, да разглеждат фотографи и да оценяват снимки.

## Изисквания

- Python 3.10 или по-нова версия
- pip

За локално стартиране не са нужни външна база данни, API ключове или други credentials. Проектът използва SQLite и записва качените снимки в локалната директория `media/`.

## Инсталиране

Отворете терминал в главната директория на проекта и изпълнете:

```bash
python -m venv .venv
```

Активирайте виртуалната среда.

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Инсталирайте зависимостите:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## База данни и стартиране

Приложете миграциите и стартирайте локалния сървър:

```bash
python manage.py migrate
python manage.py runserver
```

Отворете [http://127.0.0.1:8000/](http://127.0.0.1:8000/) в браузър.

Първоначалните обекти не се зареждат автоматично. Добавете фотограф от страницата **Photographers**, след което качете снимка от **Gallery**. При качване изберете фотограф, въведете заглавие и файл, после изберете съществуващи автомобили или добавете автомобил във формата. Не е необходимо да използвате Django admin.

## Тестове и проверки

```bash
python manage.py test
python manage.py check
python manage.py makemigrations --check --dry-run
```

## Структура на проекта

- `car_photography/` — основни Django настройки и URL маршрути.
- `pages/` — начална страница и обща страница за грешка 404.
- `photographers/` — модели, форми и CRUD страници за фотографи.
- `photos/` — автомобили, снимки, качване, редактиране, търсене и галерия.
- `ranking/` — оценки и класация.
- `media/` — качени файлове в локална разработка.
- `db.sqlite3` — локална SQLite база данни, създадена/обновена чрез миграциите.

## Настройки за локална разработка

Настройките са в `car_photography/settings.py`. По подразбиране `DEBUG = True`, базата е SQLite, а `MEDIA_ROOT` сочи към `media/`. Не са необходими environment variables за локален старт.

За проверка на персонализираната 404 страница задайте временно `DEBUG = False` и добавете `127.0.0.1` към `ALLOWED_HOSTS`, след което отворете несъществуващ адрес. Върнете `DEBUG = True` след проверката. Не използвайте development `SECRET_KEY` или `DEBUG = True` при публично production разгръщане.
